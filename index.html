02 / Interactive evaluation example

Can you spot the unsupported claim?

A short synthetic exercise demonstrates evidence-based judgment. Select the response that follows the supplied policy rather than the one that sounds confident.

Task brief

Apply the rule. Ignore invented details.

A customer bought a $24 item 12 days ago. The item is unused.

Supplied policy: Refunds are available within 30 days for unused items.

  • Check both eligibility conditions.
  • Do not add a restriction absent from the policy.
  • Explain the decision using the given evidence.

Synthetic scenario, not a real customer interaction.

Response A
“Yes. The item meets the stated conditions: it is unused and the purchase was within 30 days.”
Response B
“No. Refunds are only available within 7 days, even for unused items.”
Which response is better supported?
