# Advanced Blind Evaluation

A five-case paired-response assessment designed to test judgment beyond obvious correctness checks.

## Instructions

1. Read [the challenge](challenge.md) and [the methodology](methodology.md).
2. Complete the [blank evaluation worksheet](evaluation-template.csv).
3. For every case, choose A, B, or Tie; score both responses on the five dimensions; record confidence, decisive evidence, and actionable feedback.
4. Do not open the answer key until you have completed and saved your judgments.

The cases test comparative severity, instruction compliance, subtle unsupported claims, calibration of uncertainty, and reasoning validity.

## Scope

This is a self-directed synthetic exercise. Its answer key is an author-created reference, not an independently adjudicated gold standard. Results should be reported as agreement with this reference only—not as a validated measure of professional competence.
