## Evidence boundaries
All examples are self-directed. Datasets are synthetic unless a source is explicitly identified. They are not paid client work, proprietary production data or independently validated benchmark results. Scores against author-created references do not establish independent proficiency. Independent annotator agreement and candidate production throughput remain unmeasured. The production-style assessment pack is prepared but has not been completed by the candidate.

Governance simulation results are generated from synthetic fixtures and deterministic exercise rules. They do not establish real system control implementation or operating effectiveness. Governance artifacts are not legal advice, audit opinion, certification or compliance determination. The initial free-model security evaluation is a seven-case, single-trial exercise with dynamic model routing; it is not a benchmark, does not establish generalizable model safety, and has not yet received independent human adjudication. The report includes provider request IDs and observed response excerpts; the full raw provider-response export is not committed.

## Method
Parse instructions; identify evidence and unknowns; apply a documented rubric; record source-grounded rationale; flag ambiguity; validate structure; document limitations and corrective actions.
