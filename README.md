## Evidence boundaries
All examples are self-directed. Datasets are synthetic unless a source is explicitly identified. They are not paid client work, proprietary production data or independently validated benchmark results. Scores against author-created references do not establish independent proficiency. Independent annotator agreement and candidate production throughput remain unmeasured. The production-style assessment pack is prepared but has not been completed by the candidate. The 30 tasks and reference labels are both present in this public repository. The reference file is separate from the task file but is not access-controlled; this is an honor-system practice assessment, not a secure blind test. Candidate results should only be reported if the candidate independently completes and freezes the submission before consulting the reference labels.

Governance simulation results are generated from synthetic fixtures and deterministic exercise rules. They do not establish real system control implementation or operating effectiveness. Governance artifacts are not legal advice, audit opinion, certification or compliance determination. The free-model security evaluation comprises seven scenarios executed twice (14 case-level trials) with dynamic model routing and synthetic tools. Two trials per scenario are insufficient for a reliable attack-success estimate or generalizable safety conclusion; independent human adjudication has not yet been recorded. The report includes provider request IDs and observed response excerpts; the full raw provider-response export is not committed. The new repeated-trial ledger is intentionally populated only with `not_run` placeholders until real trials are executed and their raw evidence preserved.

## Method
Parse instructions; identify evidence and unknowns; apply a documented rubric; record source-grounded rationale; flag ambiguity; validate structure; document limitations and corrective actions.
