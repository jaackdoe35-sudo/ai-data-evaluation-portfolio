# Project 05 — Realistic AI Response Review

A scenario-based assessment using longer responses, competing quality dimensions, incomplete evidence, and realistic user-facing tasks.

## How to complete

1. Read [the scenario pack](scenarios.md) and [the review protocol](review-protocol.md).
2. Complete [the evaluation worksheet](evaluation-template.csv).
3. Write a concise evidence-based rationale for every case. Identify strengths as well as defects.
4. Do not open the reference key until your worksheet and rationales are complete.

This assessment is intentionally less binary than the earlier paired-response exercises. Some cases require calibrated judgment rather than simply finding one obvious error.

## Scope

All scenarios and data are synthetic. The reference key is an author-created guide, not an independently adjudicated gold standard. Results are practice evidence only.
