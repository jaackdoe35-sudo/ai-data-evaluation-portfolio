METHOD / EVIDENCE DISCIPLINE

Make the result
reproducible.

Define the question, preserve the source, record what happened, and state what the evidence cannot establish.

01 / SCOPE

Define the system and objective

Record authorized scope, evaluation question, expected behavior and success criteria.

02 / DESIGN

Predefine the method

Version prompts or test cases, rubric, trial conditions and outcome labels before interpreting results.

03 / EXECUTE

Preserve raw observations

Capture exact inputs, outputs, tool traces where available, timestamps, model metadata and deviations.

04 / ADJUDICATE

Classify evidence conservatively

Distinguish verified events from reported outcomes, inference, inconclusive observations and tests not run.

05 / REPORT

Explain findings and limits

Connect each finding to evidence, impact, uncertainty, remediation and retest criteria.
