# Transcription Practice Sample

**Status:** Illustrative, self-authored sample. This is not a recording transcript and was not generated from an audio file.

## Source status

No source audio is attached to this exercise. The text below is a constructed example used to demonstrate transcript formatting and uncertainty conventions. It must not be presented as an actual audio transcription.

## Sample transcript

**Speaker 1:** Good morning. I wanted to ask whether the training session is still scheduled for Thursday.

**Speaker 2:** Yes, it is scheduled for Thursday at ten in the morning. We will send the meeting link later today.

**Speaker 1:** Thank you. Should I prepare anything before the session?

**Speaker 2:** Please review the short introduction document. There is no need to install any software.

## Formatting conventions demonstrated

- Use speaker labels consistently.
- Preserve the meaning and sequence of the spoken content.
- Do not add information that is not present in the source.
- Use `[inaudible]` only when audio is genuinely unclear.
- Use timestamps when requested by the client or required by the task.
- Do not claim verbatim accuracy without checking the audio.
