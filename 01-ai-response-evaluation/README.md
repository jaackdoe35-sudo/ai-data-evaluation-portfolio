# Project 01 — AI Response Evaluation

This practice project contains a five-dimension rubric, 30 synthetic prompt/response evaluations, and a findings report.

## Files

- `evaluation-rubric.md` — scoring definitions and severity guidance.
- `evaluated-responses.csv` — 30 labeled examples with evidence rationales.
- `findings-report.md` — descriptive summary and limitations.

All examples are synthetic. Scores are illustrative human judgments, not benchmark measurements of a named model.
