# Skills and Working Methodology

This document describes the methods demonstrated in this practice portfolio. It does not claim formal certification or paid work experience.

## Demonstrated skills

- **AI response evaluation:** Applying a multi-dimensional rubric and recording evidence-based rationales.
- **Text annotation:** Applying a fixed intent and sentiment taxonomy to short messages.
- **Guideline writing:** Defining labels, boundaries, examples, and ambiguity handling.
- **Quality assurance:** Checking row counts, required fields, unique identifiers, label schema, and distribution.
- **Written communication:** Producing concise findings and documenting limitations.
- **Data handling:** Working with structured CSV files and preserving source text.

## Evaluation workflow

1. Parse the task requirements and identify explicit constraints.
2. Identify what evidence is available and what is missing.
3. Apply the rubric dimension by dimension.
4. Write a rationale that points to observable behavior.
5. Mark uncertainty and escalate high-impact failures.
6. Review scores for consistency before reporting.

## Annotation workflow

1. Read the full text.
2. Identify the primary communicative purpose.
3. Apply the documented label definitions.
4. Assign sentiment based on explicit language.
5. Add a concise rationale.
6. Run structural and consistency checks.

## Tools used in this portfolio

- GitHub for version-controlled documentation and datasets.
- CSV-compatible spreadsheet tools for inspecting tabular annotations.
- Markdown for guidelines, reports, and documentation.

No proprietary evaluation platform, client dataset, or paid annotation tool is represented as having been used.

## Professional principles

- Accuracy over speed when a label is uncertain.
- Follow the task instructions and schema exactly.
- Protect personal and confidential information.
- Never fabricate missing source details.
- Separate observed facts from interpretations.
- Disclose synthetic data and methodological limitations.
