# Project 03 — Paired AI Response Evaluation Challenge

**Purpose:** Demonstrate comparative evaluation, evidence-based preference decisions, error detection, and actionable evaluator feedback.

**Data status:** All prompts and candidate responses are synthetic and authored for this exercise. This is not a benchmark of a named model.

## Files
- challenge.md — ten paired-response cases; attempt these before opening the key.
- evaluation-template.csv — blank scoring worksheet.
- answer-key.md — reference decisions and evidence-based rationales.
- methodology.md — evaluation procedure and scoring guidance.

## Recommended procedure
1. Read methodology.md.
2. Complete all ten cases in challenge.md.
3. Record separate scores for A and B in evaluation-template.csv.
4. Write a specific rationale and actionable feedback for each case.
5. Only then compare your work with answer-key.md.
6. Record disagreements and what evidence resolved them.

The answer key is an authored reference judgment, not an infallible gold standard. Do not claim inter-rater agreement from a single evaluator.
